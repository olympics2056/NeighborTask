NeighborTask Concierge 🍌A "Nano Banana" styled peer-to-peer service platform connecting neighbors for tasks like snow removal, lawn care, and cleaning. Built with a Single-File React Frontend and a Google Apps Script Backend (Serverless).Project Structureindex.html: The complete frontend website. Hosted on GitHub Pages or Netlify.app_script_backend.js: The server-side logic. Hosted on Google Apps Script.Setup Guide1. Deploy the BackendCreate a new Google Sheet.Go to Extensions > Apps Script.Copy the code from app_script_backend.js and paste it into the script editor.Important: Replace YOUR_SPREADSHEET_ID_HERE (Line 11) with your actual Google Sheet ID.Click Deploy > New Deployment.Select type: Web App.Execute as: Me.Who has access: Anyone (Critical for the frontend to connect).Copy the Web App URL.2. Connect the FrontendOpen index.html in a text editor.Find Line 67: const BACKEND_URL = "";Paste your Web App URL inside the quotes.Save the file.3. Host on GitHub PagesUpload index.html to this repository.Go to Settings > Pages.Select the main branch and click Save.Your site is live!FeaturesDual Mode: Switch between Customer (Requesting help) and Helper (Earning money).Smart AI Chat: Infers property details and prices automatically.Visual Schematics: Displays SVG diagrams of driveways/lawns for confirmation.Map Integration: Shows verified neighborhood zones.Safety Logic: Enforces background checks for high-risk tasks (Childcare).
